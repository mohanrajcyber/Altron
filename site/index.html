Run it on your machine

The public page is the front door. The core runs locally.

GitHub Pages serves this project homepage only. ALTRON’s microphone-to-action interface needs its Python server on your PC; a public static page cannot open apps on your computer.

The speech capture uses the browser speech service. Network or permission failures are reported in the local app; API credentials belong in your private .env, never in GitHub.
# Clone the project
git clone https://github.com/mohanrajcyber/Altron.git
cd Altron

# Windows: configure your private .env, then launch
copy .env.example .env
START_ALTRON.bat

# Or use Python directly
python -m pip install -e .
python -m altron app
