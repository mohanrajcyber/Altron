# Localhost Port Scanner (Educational)

A simple TCP connect port scanner with a clean Tkinter UI.  
**Security restriction:** The scanner will only accept `127.0.0.1`, `localhost`, or `::1` as targets. Any other input is rejected.

## Files
- `scanner.py` – Main application (run with `python scanner.py`)
- `requirements.txt` – Empty (standard library only)
- `README.md` – This document
