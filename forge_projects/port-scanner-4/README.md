# Localhost Port Scanner (Educational)

A simple TCP port scanner with a clean Tkinter UI.  
**Safety restriction:** The scanner will only accept `127.0.0.1` or `localhost` as a target. Any other input is rejected.

## Files
- `scanner.py` – Main application (run with `python scanner.py`)
- `requirements.txt` – Empty (uses only Python standard library)
