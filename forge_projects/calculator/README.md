# ALTRON Calculator

A simple desktop calculator built with Python's Tkinter library.

## Features
- Basic arithmetic: `+ - * /`
- Percentage (`%`)
- Clear (`C`) and backspace (`⌫`)
- Keyboard support (numbers, operators, Enter, Backspace)
